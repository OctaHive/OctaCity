# OctaCity Agent Implementation Plan

The implementation plan is split by responsibility so each document remains navigable and reviewable:

- [Architecture and contracts](agent-implementation-plan/architecture.md): goals, fixed decisions, system shape, protocols, configuration, job state, source acquisition, and execution backends.
- [Operations and lifecycle](agent-implementation-plan/operations.md): resource accounting, runner supervision, durable delivery, security, outputs, caching, cleanup, shutdown, and observability.
- [Delivery roadmap](agent-implementation-plan/delivery-roadmap.md): implementation phases, server handoff, performance tests, completion criteria, deferred work, and the first coding milestone.

Together these documents preserve the original plan; this file is the stable entry point linked from the repository README.
